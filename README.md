# Ludo Game Android

Production-ready native Android Ludo game application with online multiplayer, offline AI, and AdMob monetization.

## Features
- Online multiplayer with Firebase
- Offline AI opponents
- Local multiplayer (2-4 players)
- Complete Ludo rules implementation
- AdMob integration
- User authentication
- Daily rewards system
- Leaderboard
- Dark/Light mode

## Tech Stack
- Kotlin
- MVVM + Clean Architecture
- Hilt DI
- Firebase Auth + Realtime DB
- Room DB
- Coroutines + Flow
- Retrofit + WebSockets
